# Artwork Artist Classification — EfficientNet Transfer Learning

Классификация произведений искусства по автору с использованием предобученной EfficientNet. Исследование стратегий fine-tuning, аугментаций и балансировки классов.

## Актуальность и задача

Автоматическая атрибуция картин может использоваться для навигации по цифровым художественным коллекциям и анализа авторского стиля. Задача проекта — определить автора картины по изображению, сравнив стратегии переноса обучения и подходы к работе с дисбалансом классов.

**Датасет:** [изображения и метаданные художников](https://disk.yandex.ru/d/_BUueJa4RVXplQ), включая `artists.csv` и каталоги `images/train`, `images/test`.

## Методы

- **EfficientNet:** fine-tuning с заморозкой feature extractor, частичной разморозкой и дообучением всех слоёв.
- **Аугментации изображений:** сравнение базовой предобработки с расширенным набором преобразований.
- **Дисбаланс классов:** сравнение результатов на наиболее представленных художниках и расширенном наборе из 50 классов; взвешенная `CrossEntropyLoss`.
- **Эксперименты:** PyTorch Lightning и Weights & Biases.

## Метрики

| Метрика | Назначение |
| --- | --- |
| **Macro-F1** | Основная метрика: одинаковый вес каждого автора |
| **Train / validation loss** | Контроль обучения и обобщающей способности |
| **F1 для частых и редких авторов** | Анализ качества при дисбалансе классов |

## Основные результаты

- Аугментации повысили macro-F1 с **0.79926 до 0.84117** в сравнении, представленном в ноутбуке.
- При взвешивании классов F1 для редко представленных авторов увеличился с **0.504 до 0.542**.
- В ноутбуке сохранены графики обучения, визуализации изображений и результаты экспериментов с различными стратегиями fine-tuning.
